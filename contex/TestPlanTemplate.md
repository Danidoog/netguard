**Preparado por :** Nombre Tester

1. # **Introducción**

   Shopping Cart es una aplicación web que permite a los usuarios agregar productos de un catálogo a su carrito de compras o su lista de favoritos, para luego poder realizar la compra según sus selecciones y gustos.

2. # **Alcance de las pruebas (Que se va a probar?)**

   Se probarán las siguientes historias de usuario definidas en el sprint backlog.

| Ticket | Descripción de la historia |
| :---- | :---- |
| **RF01** | Registro de usuarios |
| **RF02** | Página de Login |
| **RNF01** | Interfaz del Sistema |
| **RNF08** | Sistema de ayudas |

3. # **Fuera del Alcance**

   1. Pruebas de rendimiento (carga, stress, concurrencia)

   2. Pruebas de seguridad.

4. # **Tipos de la prueba / estrategia (Cómo ejecutar las pruebas?)**

   1. Pruebas ágiles/ funcionales basadas en historias de usuario \+ exploración.

   2. Cross browser testing (multiples browsers)

   3. Cross mobile testing (Emulado con Chrome)

   4. Pruebas de Aceptación de usuario (UAT)

   5. Pruebas de sanidad del reléase una vez en Producción.

5. **Ambiente de prueba https\://shoppingcart.testing.net/** (sitio web o servidor)

7. # **Riesgos**

| Riesgo | Probabilidad | Impacto | Mitigación |
| :---- | :---- | :---- | :---- |
