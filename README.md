# NetGuard

Sistema de monitoreo y análisis de redes orientado a la detección de dispositivos y servicios disponibles dentro de una red autorizada.

## Tecnologías

- Python
- FastAPI
- Nmap
- React
- TypeScript
- Git

## Estructura

- `backend/`: API y lógica del sistema.
- `frontend/`: interfaz gráfica.
- `docs/`: documentación del proyecto.
- `tests/`: pruebas automatizadas.
